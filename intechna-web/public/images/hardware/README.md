# Hardware illustrations

AI-generated hardware renders prepared for the Intech redesign. They illustrate
device categories and infrastructure; they are not official manufacturer photos
or a source of model specifications. Do not use them to assert a device's exact
ports, dimensions, compatibility or technical configuration.

Visual direction: neutral titanium / dark hardware, clean studio lighting,
transparent background and minimal decoration. The original PNGs were generated
by the image-generation tool in this chat. This directory contains WebP exports
only; conversion preserved alpha and applied proportional resizing, without
retouching the imagery.
